# Image assets

The official Vijaya Premix logo and seven authoritative product artworks are
bundled here unchanged. Product cards, cart, search, recipes and modals all
read their local image paths from `assets/js/data.js`.

- `products/` — the seven supplied product pack JPEGs
- `recipes/` — reserved for future official recipe photography
- `hero/` — homepage hero + login/signup side-panel imagery
- `brand/` — official `vijaya-premix-logo.jpeg` plus the existing favicon
